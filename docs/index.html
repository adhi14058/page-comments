page-comments

Point at things on any web page, say what should change, and hand it to Claude Code, Slack, Jira or a teammate.

Add the bookmark

Grab the orange button and drag it up into your bookmarks bar. No bar? Show it with Ctrl+Shift+B (⌘+Shift+B on a Mac).

This is version 1.9.0. This bookmark never loads code from the internet: it runs this version until you drag a newer one.

To use it, open any page and click the bookmark. Commenting is on straight away. After a reload, click it again: your comments come back.

New version: open, then re-drag the bookmark

Updates. When a newer version is out, the round button gets a green dot (it checks a small image on page-comments.share.heyadhi.com; where that site is blocked there is no dot). Download this page again from GitHub (Code → Download ZIP, then open docs/index.html), delete the old bookmark and drag the new one. Your comments are kept.

Several things at once

One comment can cover a part of the page, or a set of elements.

An area A

Press A (or Select an area) and drag a box over the page. Good for gaps, empty space, or things side by side.

A batch B

  1. Press B (or Select several). Shift+click on an element starts a batch too.
  2. Click each element you want. A second click removes it. The page scrolls as you go.
  3. Need a part of the page, not an element? Press A and drag boxes. A again goes back to elements.
  4. Press Enter (or Comment on the blue bar). You write one comment for all of them, with a picture of each: 2a, 2b, 2c…

Close without saving or Esc asks before it drops what you picked. In the comment box, ‹ › step through the selections.

Hover menus and tooltips

Menus and tooltips vanish when the mouse moves. Freeze turns the page into a still picture, so they stay put. You click, drag over and right-click the picture just like the live page.

Press F

Hover the thing so it opens, then press F.

Use the countdown

Click Freeze in the bar. You get 3 seconds to open the menu with your mouse. Then it freezes.

The first time, Chrome asks to share the tab. That first press only starts sharing, because the prompt closes open menus. Open the menu again and freeze. Esc unfreezes. Alt+Shift+F freezes even while you browse.

Hand it over

Copy (C) puts every comment on this page on the clipboard: the text, the formatted version, and one stacked picture. Where are you pasting?

  1. Press C.
  2. Paste into Claude Code. Ctrl+V adds the pictures: one stacked picture, each part numbered like its comment.

Working on an app on your own machine? Send to Claude skips the paste and lets Claude edit the project.

  1. Press C and paste: you get the text and one stacked picture.
  2. Want each picture on its own? Open the comments list (L) and click Save pictures. Each picture is saved as its own file, like 2a-make-it-bold.png.
  3. Select those files in your Downloads folder and drag them into Slack together.

A web page can put only one picture on the clipboard. That is why Copy stacks them.

  1. Open the comments list (L) and click Copy text. Paste.
  2. Click Copy pictures. Paste again.

Their editor drops either the text or the pictures when one paste holds both. Two pastes keep both.

  1. Press C and paste.

Each comment reads: the comment, the plain name of what it is about, its pictures, then one small grey line of details (size, colours, font, selector).

The comments list L

  • It holds every comment on this page. Copy text, Copy pictures and Save pictures are at its top; each comment has its own copy button.
  • Click a comment to open it: the page scrolls to it and shows what it covers, dashed.
  • A click outside the list closes it. Clear all, the bin left of the comments button, deletes this page's comments (click it twice).

Share with someone

A share link carries your comments to another person's browser. They see them on the same page, with your name.

  1. Press S (or Share link). The first time, a bar asks your name. Shift+S changes it later.
  2. The link is copied. It holds this page's address and your comments, with small copies of the pictures while the link stays under 30 KB.
  3. Send it. The other person opens it and clicks their bookmark. Your comments and pins appear next to theirs, in your colour, with your name.

Send to Claude optional only on local pages

For your own app running on this machine: Send to Claude passes the comments and pictures to Claude Code, which edits the project's source. Everywhere else, Copy does the job.

It needs a small server, Node 18+ and the claude CLI. Send shows only on pages served from your own machine: localhost, *.localhost, and names your hosts file (/etc/hosts) points at 127.0.0.1.

Set up the server

Paste this into your terminal (bash or zsh). It writes the server to ~/page-comments-server.js; run it again after an update.

cat > ~/page-comments-server.js <<'PAGE_COMMENTS_SERVER'
const { createServer } = require('node:http');
const { spawn } = require('node:child_process');
const fs = require('node:fs');
const os = require('node:os');
const path = require('node:path');

const PROMPT = 'Below are comments a user left on elements of a web page. Find the code in this project behind each element (from its selector, text and HTML) and make the change asked for.\n\n';
const HOSTS = process.env.HOSTS_FILE || (process.platform === 'win32' ? path.join(process.env.SystemRoot || 'C:\\Windows', 'System32', 'drivers', 'etc', 'hosts') : '/etc/hosts');
const hostsNames = () => {
  try {
    return fs.readFileSync(HOSTS, 'utf8').split('\n').flatMap((line) => {
      const [ip, ...names] = line.replace(/#.*/, '').trim().split(/\s+/);
      return /^(127\.\d+\.\d+\.\d+|::1)$/.test(ip) ? names.map((n) => n.toLowerCase()) : [];
    });
  } catch {
    return [];
  }
};
const isLocal = (origin) => {
  let url;
  try { url = new URL(origin); } catch { return false; }
  const host = url.hostname;
  return /^https?:$/.test(url.protocol) && url.origin === origin &&
    (host === 'localhost' || host.endsWith('.localhost') || host === '[::1]' || /^127\.\d+\.\d+\.\d+$/.test(host) || hostsNames().includes(host));
};
const env = Object.fromEntries(Object.entries(process.env).filter(([k]) => !k.startsWith('CLAUDE')));
let busy = false;

process.chdir(process.argv[2] || '.');
createServer((req, res) => {
  const origin = req.headers.origin;
  const reply = (code, msg) => res.writeHead(code, isLocal(origin) ? { 'Access-Control-Allow-Origin': origin } : {}).end(msg);
  if (!isLocal(origin)) return reply(403, 'origin not allowed');
  if (req.url === '/health') return reply(200, 'ok');
  if (req.method !== 'POST' || req.url !== '/comments') return reply(404, 'not found');
  if (busy) return reply(409, 'Claude is still working on the last batch');
  let body = '';
  req.on('data', (chunk) => (body += chunk).length > 30e6 && req.destroy());
  req.on('end', () => {
    let text, images;
    try {
      ({ text, images = [] } = JSON.parse(body));
    } catch {
      return reply(400, 'update the bookmark: this server expects its newer format');
    }
    if (typeof text !== 'string' || !Array.isArray(images)) return reply(400, 'bad request');
    busy = true;
    const dir = fs.mkdtempSync(path.join(os.tmpdir(), 'page-comments-'));
    images.forEach((pics, i) => [].concat(pics || []).forEach((url, k, all) => {
      const [, type, data] = /^data:image\/(png|webp|jpeg);base64,(.+)$/.exec(String(url)) || [];
      const tag = all.length < 2 ? '' : k < 26 ? String.fromCharCode(97 + k) : '-' + (k + 1);
      if (data) fs.writeFileSync(path.join(dir, `screenshot-${i + 1}${tag}.${type === 'jpeg' ? 'jpg' : type}`), Buffer.from(data, 'base64'));
    }));
    const note = images.some(Boolean) ? `\n\nThe screenshots are in ${dir}: screenshot-N (or Na, Nb, ... when a comment has several) belongs to comment N. Look at them.` : '';
    spawn('claude', ['-p', PROMPT + text + note, '--permission-mode', 'acceptEdits', '--add-dir', dir], { env, stdio: ['ignore', 'inherit', 'inherit'] })
      .on('error', (err) => console.error('could not start claude:', err.message))
      .on('close', () => {
        busy = false;
        fs.rmSync(dir, { recursive: true, force: true });
      });
    reply(202, 'sent');
  });
}).listen(4747, '127.0.0.1', () => console.log('page-comments on http://localhost:4747, project:', process.cwd()));
PAGE_COMMENTS_SERVER

Then start it, pointing at the project that renders the page. Claude runs in that folder and edits its source files.

node ~/page-comments-server.js ~/projects/my-app

The server refuses every other website: any site you visit can send requests to your machine, and without this check one could make Claude edit your code.

Good to know

  • A bookmark cannot run by itself after a reload. Click it again to bring back the round button and your comments.
  • Comments are stored in the site's own storage. Clearing the site's data deletes them, and the site's scripts could read them.
  • If the page changed and an element cannot be found again, its pin hides. The comment stays in the list and in Copy.
