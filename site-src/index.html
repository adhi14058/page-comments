Details and a contrast check

Press D while pointing: size, colours, font, padding and radius. Contrast gets a ✓ or ✗ by the WCAG rule. The comment box copies the selector.

Large text passes at 3:1: 24 px, or 18.66 px bold. Smaller text needs 4.5:1.

Send to Claude only on local pages

A small server on your computer hands your comments and pictures to Claude Code, which edits your app's source. Needs Node 18+ and Claude Code (the claude command).

  1. 1Save the serverPaste this into a terminal (bash or zsh). Paste it again when Page Comments updates.
    ~/page-comments-server.js
    {{serverCode}}
  2. 2Start it in your project
    node ~/page-comments-server.js ~/projects/my-app

    Change the path to the folder of the app you're commenting on.

The server refuses every other site, so no website can make Claude edit your code.

Good to know

  • The round button is blue while you comment and orange while you browse. Click it to switch, drag it to move. The small × beside it closes the tool.
  • A bookmark does not run by itself after a reload. Click it again: your comments come back.
  • Comments live in the site's own storage. Clearing its data deletes them.
  • If an element is gone, its pin hides. The comment stays in the list.
  • Frames from the same site work too: comment on what they show.
